# Матен — энциклопедия мира

Статическая вики мира Матен для кампании «Шрам Матена». Редакция II, 2 октября 2026 года.

Содержание хранится в `content.json`. Студия статей создаёт из него HTML, указатели и индекс поиска. Редактируйте материалы через Студию, чтобы все страницы оставались согласованы.

Общие стили: `maten.css` и `atlas.css`. Поиск, оглавления и мобильная справка: `wiki.js`.

Исходная версия до обновления сохранена в `.maten-studio-backups/upgrade-20261002/`. Полный откат сайта и программы запускается файлом `restore-before-upgrade.cmd` из папки Студии. Подробности — в `UPGRADE-AND-ROLLBACK.md` рядом с программой.

Сайт: https://snowbordist.github.io/maten-wiki/
