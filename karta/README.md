# Карта Матена

Модель и география импортированы из пользовательского атласа «Матен 3D».
`maten.glb` — исходная модель; `overview.png` — вид сверху. Исходные Blender-файлы не менялись.
Three.js 0.180.0 поставляется локально, лицензия — `vendor/LICENSE.txt`; внешнего CDN нет.

`index.html` генерируется вместе с остальной вики функцией `Maten.build` в `core.js` Студии.
Ручные правки этой страницы будут заменены при следующем сохранении. Меню и страница карты уже включены в генератор и в EXE Студии версии 3.2.0.

Связи находятся в `content.json`, поле `mapLinks`: ключ — ID поселения (`settlement-01`), значение — ID существующей статьи (`mir/…`). Редактируйте их через раздел «Карта» Студии. Изначально все места не связаны; автоматического сопоставления названий нет.

`place-articles.js` читает описание из той же статьи в `content.json`, которой пользуется генератор. Отдельной редактируемой копии текста нет. Если краткое описание пустое, показывается начало статьи; полный текст открывается по ссылке. После публикации изменений перезагрузите карту.

`places.json` используется Студией; `places.js` — 3D-сценой. Оба файла получены из одного `settlements-3d.json` атласа. Не меняйте ID поселений при обновлении геометрии, иначе существующие связи перестанут соответствовать местам.

Загрузка GLB начинается по кнопке; при недоступности 3D остаётся обычная карта. Модель занимает около 22 МБ. Высоты и масштаб построек художественные.
