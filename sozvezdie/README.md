# Созвездие статей

Страница генерируется `Maten.build` из `core.js` Студии. Навигация и ссылка на главной включены в генератор и пересобранное приложение Студии.

Скрипт читает актуальный `content.json`: узлы — статьи, сплошные линии — `related` (показываются в обе стороны), пунктир — разделы. Неизвестные ID и повторные связи пропускаются. Текст статей не изменяется. Иллюстрации берутся из материалов вики.

Поиск учитывает названия и псевдонимы. Доступны фильтры, масштаб, перемещение фона и клавиатурный выбор узлов. Адрес с хешем сохраняет выбранную статью.
